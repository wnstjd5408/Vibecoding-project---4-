# MEG-258 CS Agent 기본 흐름 화면: 목업 대조 스크린샷

`screens/`의 이미지는 왼쪽에 캔버스 보드를, 오른쪽에 구현 화면을 놓았다(AC-1).

- **목업:** Claude Design 캔버스의 F6 보드를 정적 HTML로 그려 찍었다. 캔버스 Version 96 문구 기준이고, 보드 파일은 2026-11-20에 읽었다.
- **구현:** `tests/agentPanel.spec.ts`가 가짜 API(`VITE_API_MOCK=true`)로 각 상태를 띄워 찍었다. 모델은 부르지 않았다. 답변 문구는 가짜 API의 합성 문구라서 목업 문구와 다르다. 비교 대상은 화면 구조와 상태별 문구다.
- **다시 만들기:** `frontend`에서 아래 명령을 실행하면 구현 스크린샷이 `<폴더>/<보드 ID>.png`로 저장된다.

  ```powershell
  $env:AGENT_SHOT_DIR='<폴더>'; npx playwright test tests/agentPanel.spec.ts
  ```

- **노트 근거 기간:** 캔버스 보드는 위키 문구다(14.5, 캔버스 수정 안 함). 구현은 디자인 v0.2 14.5의 '노트 근거 기간' 문구를 쓴다. 예: '노트에서 자료 찾기', '[1] 노트 · 제목 · 절', 'CS 노트'.
- **모바일 보드가 없는 상태:** 사용 제한, 응답 지연, 새 답변 보기, 다시 넣기 확인 등은 모바일에 그리지 않았다(2026-11-20 결정 8, MEG-263). 그래서 해당 모바일 비교 이미지가 없다.
