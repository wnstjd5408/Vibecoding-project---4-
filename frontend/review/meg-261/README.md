# MEG-261 CS Agent 보기 전환: 목업 대조 스크린샷

`screens/`의 이미지는 왼쪽에 캔버스 보드를, 오른쪽에 구현 화면을 놓았다(AC-1).

- **목업:** Claude Design 캔버스의 F6-3(패널), F6-3f(떠 있는 창), F6-3x(전체 화면) 보드를 정적 HTML로 그려 찍었다. 보드 파일은 2026-11-20에 읽었다(캔버스 Version 102). F6-3f·F6-3x는 사람 검토 전 보드다.
- **구현:** `tests/agentViewModes.spec.ts`의 AC-1 시험이 가짜 API(`VITE_API_MOCK=true`)로 같은 대화를 띄운 채 세 보기를 오가며 찍었다. 모델은 부르지 않았다. 답변 문구는 가짜 API의 합성 문구라 목업 문구와 다르다. 비교 대상은 창의 위치·크기와 머리 버튼, 화면 구조다.
- **전체 화면의 길이:** 목업은 긴 보드(1280×1240)이고, 구현은 1280×800 화면 안에서 대화 영역만 스크롤한다. 그래서 구현 이미지에는 답변 윗부분만 보인다.
- **다시 만들기:** `frontend`에서 아래 명령을 실행하면 구현 스크린샷이 `<폴더>/<보드 ID>.png`로 저장된다.

  ```powershell
  $env:AGENT_SHOT_DIR='<폴더>'; npx playwright test tests/agentViewModes.spec.ts
  ```

- **노트 근거 기간:** 캔버스 보드는 위키 문구다(14.5, 캔버스 수정 안 함). 구현은 노트 근거 기간 문구를 쓴다.
- **다시 답하기:** 목업의 '다시 답하기' 버튼과 안내는 만들지 않는다(MEG-228, spec 부록 A).
