# 완료 기준 (completion)

`AGENTS.md`에서 옮긴 절차다. 이슈를 In Review·Done으로 옮길 때, 조사·실험·릴리스 티켓을 다룰 때, 배포가 AC에 포함될 때 읽는다. AC별 검증 기록과 Done 독단 전환 금지는 `AGENTS.md`에 있다.

## 산출물과 조사·실험
- 코드·문서 산출물 티켓은 모든 AC가 해당 PR에서 끝날 때 필요한 테스트·사람 리뷰·병합으로 완료할 수 있다.
- 조사·실험 수행과 릴리스 티켓은 실제 수행 범위의 AC 및 사람의 수락까지 확인한다. 중간 산출물 PR은 별도 이슈에 연결하고 원 작업은 Linear 내부 관계로 연결해 조기 자동 완료를 막는다.

## 릴리스
- 배포가 AC에 포함되면 릴리스 티켓으로 원문·출처와 함께 이관하고 구현 티켓과 연결한다. 배포 조건을 삭제해 완료로 만들지 않는다. 릴리스는 환경·버전·URL·동작 확인·복구 근거와 사람의 출시 결정/결과 수락을 남긴다. 실패한 배포는 미완료다.
- 프로젝트 출시 여부는 릴리스 근거로 판단한다. 배포 후 사용자 관찰 결과를 다음 탐색·결정에 연결한다.

## PR 자동화
- 2026-10-18 확인된 PR 자동화는 생성 → In Review, 병합 → Done이다. 목표인 draft → In Progress, ready → In Review는 설정·실제 이벤트 확인 전 적용됐다고 쓰지 않는다. 자동화가 움직인 상태를 임의로 되돌리지 않고 실제 작업 단계와 차이를 기록해 담당자와 바로잡는다.
