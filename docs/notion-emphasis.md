# Notion 강조 공백 변환 (MEG-196)

굵게·기울임의 각 줄에서 선행/후행 공백을 구분자 밖으로 옮긴다.
공백·탭·줄바꿈은 삭제하지 않는다. 빈 문자열과 공백만 있는 문자열에는
구분자를 만들지 않는다. 동일 서식·링크의 인접 run은 합쳐 별표 충돌을 막는다.
코드의 기존 변환과 링크 주소는 유지하며 일반 글자의 별표는 이스케이프한다.

예: `**예시용어 **(Example)` → `**예시용어** (Example)`.
줄을 넘는 강조는 각 줄에 별도 구분자를 둔다. E05는 줄을 넘는 용어를 매칭하지
않는다. Markdown 블록 해석(문단 첫 들여쓰기·빈 줄)과 브라우저의 공백 표시 규칙은
변경하지 않는다. 서로 다른 서식의 공백 없는 복잡한 경계, 취소선 지원 확대는
이번 수정의 보장 범위가 아니다. 마이그레이션은 이런 후보를 자동 보정하지 않는다.

검증은 합성 입력의 가져오기 함수 → 실제 E05 span 함수 → 실제 NoteBody 렌더러를
연결한다. Playwright의 API 응답은 합성이며 실제 원격 서버/DB 시험이 아니다.
390/1280px에서 강조·복합 서식·한글/이모지·이스케이프 별표·용어 ID 및 DOM UTF-16
선택 범위를 API 코드포인트로 변환한 결과를 검증한다.

MEG-197 인계: 원문 의도는 Markdown만으로 확정하지 않는다. 원본 또는 사람 검토로
확인된 구간만 위 규칙을 적용하고, 코드·링크·이미지·정상 강조·모호한 경계는 제외한다.
MEG-170 적용 뒤에는 최신 본문/revision으로 계획과 백업을 다시 만든다.
