## 작성 기준

PRD는 무엇을 만들지 약속하는 문서다. 1–6절은 아래 '적는 것'에 답하고, 7절은 PMF 단계의 검증과 사람 결정을 기록한다.

| 절 | 적는 것 |
|---|---|
| 1. 한 문장 설명 | 누구의 어떤 문제를 무엇으로 푸는가 |
| 2. 사용자와 상황 | 누가 언제 쓰는가 |
| 3. 목표와 성공 확인 | 무엇이 되면 성공인가 |
| 4. 범위 | Must · Later · 이번에는 만들지 않는다 |
| 5. 사용자 스토리 · 완료 조건 | US-01 마다 확인 가능한 조건 |
| 6. 비기능 · 열린 질문 | 성능 · 보안 · 아직 모르는 것 |
| 7. 다음 검증과 사람 결정 | 다음에 확인할 것, 사람의 수락·개발 전환 결정 |

- 입력은 `docs/user-workflow.md` 4절 표다. 표에 없는 문제나 가설을 추가하면 출처를 따로 적는다.
- 항목 끝에 `[사실]`·`[가설]`·`[미확인]`을 붙인다. `[사실]`에는 근거 위치를 함께 적는다.
- 근거 없는 수치·기간·비율을 만들지 않는다.
