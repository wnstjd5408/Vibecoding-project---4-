# 결정 기록

제품·기술·작업 방식에 대해 사람이 내린 결정을 한곳에 모은 공개 요약이다. 개발자와 AI 에이전트는 작업을 시작하기 전에 이 파일을 읽는다.

## 규칙

- **원본은 Linear다.** 이 파일은 Linear 이슈·문서에 기록된 결정의 공개 가능한 요약이다. 내용이 다르면 원본을 따르고, 해당 이슈에 기록한 뒤 이 파일을 고친다.
- **추가만 한다.** 지난 줄은 지우거나 고쳐 쓰지 않는다. 결정이 바뀌면 새 줄을 추가하고, 옛 줄의 상태만 바꾼다.
- **ID는 다시 쓰지 않는다.** `D-001`부터 차례로 붙인다.
- **상태 값:** `유효`, `일부 대체됨 → D-0xx`, `대체됨 → D-0xx` 중 하나다.
- **원본 칸**에는 MEG 이슈 ID나 Linear 문서 제목을 적는다. URL은 적지 않는다.
- **공개 기준:** 결정자는 "운영자"처럼 역할로 적는다. 실명, 사용자 수, 비용·예산 금액, 회의 참석자 수, 외부 도구의 DB·열 이름, 계정 발급 내부 절차는 적지 않는다.
- **동기화 시점:** 결정을 만든 티켓의 PR에서 같은 줄을 함께 추가한다. PR이 없는 결정은 주 1회 모아 한 PR로 올린다.
