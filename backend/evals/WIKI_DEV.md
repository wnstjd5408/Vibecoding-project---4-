# 위키 개발용 무과금 검증

이 도구는 대표 페이지 우선 흐름의 **모의 계약 검증기**다. 실제 앱의
라우터·RLS·검색·모델을 테스트하거나 배포하는 코드가 아니다.
봉인된 최종 평가 실행기의 60개 제약을 완화하지 않는다.

## 입력과 실행

저장소 밖 비공개 디렉터리에 cases.json과 manifest.json을 둔다.
6개 ID는 WDEV01~WDEV06이며 dev 전용이다. 각 사례에는 원문,
표준어·명시된 별칭, 개념/페이지 ID, 참조 설명, 필수 개념·조건,
internal_evidence 및 evidence가 있다. 근거는 합성 문단이며 실제 DB 수집물로
표시하지 않는다. 문단에는 id/text/kind/public/revision을 기록하고
웹 문단에는 검토용 공식 URL을 둔다. manifest(cases)가 전체 내용을 해시한다.

    python -m evals.wiki_dev <private-bundle> <private-output>

T3의 private_path/atomic 저장을 재사용한다. 같은 입력은 결과가 변하지 않았을 때
재사용하고, 입력·출력 변경은 거부한다. 실제 호출 어댑터나 자격증명 설정은 없다.
출력의 토큰 수는 null(측정 안 함), 실제 외부 호출 수와 비용은 0이다.
동시 실행/강제 중단 복구는 이 개발 도구의 검증 범위 밖이다.

## 모의 흐름

- L 및 등록 별칭 각각: 지정 페이지 반환, 모의 검색·모델도 호출하지 않음.
- U: 허용된 합성 근거만 요청으로 구성하고 준비된 설명을 반환.
- 모호한 용어: 개념 선택. 미등록 표현: unsupported.
- 중복·깨진 연결·조회 오류: 오류이며 미연결 생성으로 바꾸지 않음.
- 비공개 페이지: 일반회원은 접근 가능한 연결 없음과 같은 결과,
  운영자는 페이지 열기. 비로그인 U는 로그인 요청.
- 웹 조회 실패·근거 없음·모델 실패·잘못된 출처 ID·빈 응답을 구분.
- 참조 답안과 평가 기준은 모의 모델 요청에 넣지 않음. source_id의 URL은
  근거 묶음에서 결정한다. 이미지는 이번 모의 출력에서 생략한다.

캐시를 구현하지 않으므로 수정/비공개 전환 시험은 요청 시점의 분기만 검증한다.
캐시 무효화, 실제 권한 재확인, 검색 Recall, 인용의 의미적 타당성,
실제 링크·이미지 접근성과 사용 권리, 프롬프트 주입 저항성은 미검증이다.

## T4와 결과 해석

기존 scoring.verdict/metrics를 재사용한다. 새로운 개발용 집계는 리뷰를
데이터·출력 해시에 묶고 중복/오래된 리뷰를 거부한다. 5항목은 사실·개념·조건·
이해 용이성·완결성이다. 리뷰가 없으면 pending이다.
판정 함수의 95% 경계·필수 조건 누락·중대 오류·4점 O 가능 여부를
명시적으로 꾸민 리뷰로 시험한다. 자동으로 내용의 CS 정확도를 추론하지 않는다.

실행 시 생성하는 review-template.json은 빈 검수 양식이다.
t4-pending.json은 검수 전 결과다. 모든 결과에 real_quality와 golden_set은
NOT_EVALUATED로 남는다. 정답 설명을 모의 반환한 것과 실제 모델 품질을
혼동하면 안 된다. 신규 참조 문구와 근거 묶음은 별도 사람 검토 대상이다.

    python -m pytest tests/test_eval_wiki_dev.py -q

테스트는 소켓을 차단한다. 기존 runner/scoring은 변경하지 않는다.
